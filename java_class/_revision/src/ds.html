Part B: The treasure hunt 5 pts

We propose to create a treasure hunt game. The board is a square of 5 × 5 cells. A treasure is hidden in a random cell. The player starts in the top-left cell (0, 0) and moves one cell at a time: Up, Down, Left or Right. He has at most 10 moves to find the treasure. After each move, the game displays Hot! if the treasure is at a distance ≤ 2 from the player, and Cold... otherwise (distance = |difference of rows| + |difference of columns|).

Tasks to complete:

  • A Position class characterized by the attributes row and col, and:
    • two constructors: Position(int row, int col), and Position() which creates the position (0, 0);
    • the getters;
    • move(char direction): moves the position by one cell according to 'U', 'D', 'L' or 'R'. If the move leaves the board, the position doesn't change and Move impossible! is displayed; an unknown letter displays Unknown direction!. Returns true if the position changed;
    • sameAs(Position other): returns true if the two positions are the same cell;
    • distanceTo(Position other): returns the distance between the two positions.
    Knowing that: Math.abs(x) returns the absolute value of x.
  • A Board class which includes:
    • two constants SIZE (5) and MAX_MOVES (10), usable by all the classes of the program,
    • a two-dimensional array of characters cells (each cell contains '.' at the beginning, and 'x' once visited) and the position of the treasure,
    • a constructor Board() that hides the treasure in a random cell, and a constructor Board(int row, int col) that hides it in a given cell (used to test the game),
    • markVisited(Position p) and display(Position player), which displays the board with P on the player's cell.
    Knowing that: Math.random() generates a random number between 0 and 1.
  • A Player class characterized by a name, a position and the number of moves left, with a counter of created players common to all players; a constructor Player(String name) (the player starts at (0, 0) with MAX_MOVES moves), the getters, and play(char direction) which uses one move and moves the player.
  • A TestGame class that reads the player's name, then repeats: display the board, read a direction, mark the current cell as visited, move the player and display Hot! or Cold..., until the treasure is found or there are no moves left. It then displays one of these messages:
    Bravo Sami! Treasure found in 4 moves. or Game over! The treasure was at (0, 4)
    Finally, the Player object must be destroyed: write the corresponding instructions and explain in a comment what happens.

Q1. A class is a model (mould) describing a family of objects with the same attributes and methods; an object is a concrete instance of that class, with its own identity and state (attribute values). Example: the class Car describes every car (registration, color, speed, increaseSpeed()); my white BMW X1123 is one object: Car bmw = new Car("X1123", "white", 110);. One class → as many objects as we want.
Q2. A constructor is a special method that initialises the attributes of an object when it is created. Differences: (1) same name as the class, (2) no return type, not even void, (3) called automatically, only once per object, by new (a method is called explicitly, as many times as we want). If we write no constructor, Java provides a default one (no parameters, attributes at 0/false/null). As soon as we write one constructor, the default one disappears: new Person() then gives a compilation error unless we also write Person().
Q3. balance is private: it can only be accessed by the methods of BankAccount; main is in another class, so the compiler says "balance has private access". Going through deposit(amount) lets the class check the value (if (amount > 0)), so no one can put a negative or absurd balance: the object protects the integrity of its data. A public attribute could be set to anything. This is encapsulation (data hidden, access through the object's interface = public methods).

Q6. It displays 30.
