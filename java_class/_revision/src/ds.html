Part II: model answers

Q1. A class is a model (mould) describing a family of objects with the same attributes and methods; an object is a concrete instance of that class, with its own identity and state (attribute values). Example: the class Car describes every car (registration, color, speed, increaseSpeed()); my white BMW X1123 is one object: Car bmw = new Car("X1123", "white", 110);. One class → as many objects as we want.
Q2. A constructor is a special method that initialises the attributes of an object when it is created. Differences: (1) same name as the class, (2) no return type, not even void, (3) called automatically, only once per object, by new (a method is called explicitly, as many times as we want). If we write no constructor, Java provides a default one (no parameters, attributes at 0/false/null). As soon as we write one constructor, the default one disappears: new Person() then gives a compilation error unless we also write Person().
Q3. balance is private: it can only be accessed by the methods of BankAccount; main is in another class, so the compiler says "balance has private access". Going through deposit(amount) lets the class check the value (if (amount > 0)), so no one can put a negative or absurd balance: the object protects the integrity of its data. A public attribute could be set to anything. This is encapsulation (data hidden, access through the object's interface = public methods).

Q6. It displays 30. There is only one object: new was called once. p2 = p1 copies the reference (address), not the object, so p1 and p2 point to the same object, and changing it through p2 is visible through p1. After p1 = null; p2 = null; no reference points to the object any more: it becomes unreachable and the garbage collector can destroy it (we can ask with System.gc()).
Q7. The player must make at least one guess before we can compare it with the secret number; do … while tests the condition at the end, so the body (ask, compare, count) always runs at least once. With while we would have to read a first guess before the loop (duplicated code).
(a + b) / 2: both operands are int, so it's an integer division: 11 / 2 = 5 (decimal part cut); only then is 5 converted to 5.0 for m. Fixes: m = (a + b) / 2.0; or m = (double) (a + b) / 2;

Exercise 1: output and justification

```text 3.0 3.5 1 72 1:B 2:none 2 8 12.0 10 two three ```
  • ★ L1: 7 / 2 is int division = 3, then stored as 3.0.
  • L2: the cast happens before the division: 7.0 / 2 = 3.5.
  • ★ L3: a % b = 1; then string concatenation left to right: "1 " + 7 → "1 7", + 2 → "1 72" (not 9!).
  • ★ L4: z = x copies the reference: same object, so z.label = "B" changes x. x was created first → id 1.
  • L5: new Mystery() calls this("none"); count becomes 2 → id 2.
  • L6: count is static: one shared counter, 2 objects created (z is not a new object).
  • ★ L7: overloading: twice(4) → int version (4×2 = 8); twice(4.0) → double version (4.0×3 = 12.0).
  • ★ L8: do…while runs once even though i < 10 is false at the start.
  • ★ L9: b = 2 → enters case 2; no break → falls into case 3, then break.

Exercise 3: SmartATM

```java class import java.util.Scanner; public class SmartATM { public static void main(String[] args) { final double MAX_WITHDRAW = 500.0; double balance = 1000.0; int operations = 0; char choice; Scanner sc = new Scanner(System.in); do { System.out.println("D: Deposit | W: Withdraw | B: Balance | Q: Quit"); System.out.print("Your choice: "); choice = sc.next().charAt(0); switch (choice) { case 'D': System.out.print("Amount: "); double dep = sc.nextDouble(); if (dep > 0) { balance += dep; operations++; } else { System.out.println("Invalid amount!"); } break; case 'W': System.out.print("Amount: "); double wd = sc.nextDouble(); if (wd > MAX_WITHDRAW) { System.out.println("Limit is " + MAX_WITHDRAW); } else if (wd > balance) { System.out.println("Insufficient balance!"); } else if (wd <= 0) { System.out.println("Invalid amount!"); } else { balance -= wd; operations++; } break; case 'B': System.out.println("Balance: " + balance); break; case 'Q': System.out.println("Goodbye!"); break; default: System.out.println("Invalid choice!"); } } while (choice != 'Q'); System.out.println("Successful operations: " + operations); for (int month = 1; month <= 3; month++) { balance = balance * 1.01; System.out.printf("Month %d: %.2f%n", month, balance); // (extra) println is accepted too } sc.close(); } } ```

Exercise 5: Online shop

```java class class Product { private String name; private double price; public Product(String name, double price) { this.name = name; this.price = price; } public String getName() { return name; } public double getPrice() { return price; } } class ShoppingCart { private Product[] items; private int count; public ShoppingCart(int capacity) { items = new Product[capacity]; // array of references, all null count = 0; } public boolean addProduct(Product p) { if (count == items.length) { System.out.println("Cart is full: " + p.getName() + " not added"); return false; } items[count] = p; count++; return true; } public double getTotal() { double total = 0; for (int i = 0; i < count; i++) { // count, not items.length (nulls!) total += items[i].getPrice(); } return total; } public double getTotal(double discountPercent) { // overloading return getTotal() - getTotal() * discountPercent / 100; } public int luckyDiscount() { return (int) (Math.random() * 21); // 0..20 inclusive } public void printReceipt() { for (int i = 0; i < count; i++) { System.out.println("- " + items[i].getName() + " : " + items[i].getPrice()); } System.out.println("Total: " + getTotal()); } } class Customer { private String name; private ShoppingCart cart; // an object inside an object public Customer(String name, ShoppingCart cart) { this.name = name; this.cart = cart; } public void displayProfile() { System.out.println("Customer: " + name); cart.printReceipt(); // calling the inner object's methods System.out.println("Total after 10% discount: " + cart.getTotal(10)); } } public class TestShop { public static void main(String[] args) { ShoppingCart cart = new ShoppingCart(3); cart.addProduct(new Product("Keyboard", 40.0)); cart.addProduct(new Product("Mouse", 20.0)); cart.addProduct(new Product("Screen", 140.0)); cart.addProduct(new Product("Cable", 5.0)); // 4th → cart full Customer c = new Customer("Ines", cart); c.displayProfile(); } } ```
⚠ Classic mistakes in this exercise Looping to items.length instead of count → NullPointerException on empty slots. Forgetting count++. Writing Math.random() * 20 (gives 0..19 only). Writing (int) Math.random() * 21: the cast applies to Math.random() first → always 0!
