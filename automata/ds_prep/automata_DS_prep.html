Solutions

E1

  1. \d{3} = ddd
  2. \d*(0|5) — her slide: (0-9)*(0|5). Any number ending with 0 or 5.
  3. 4\d*7 (her slide: 4.*7) — 47 ✔, 4 ✘, 417 ✔
  4. [1-9]\d{2}

E2

  1. (a*b)* = (a|b)*b → False: ε ∈ (a*b)* but ε ∉ (a|b)*b (must end with b).
    (ab)*a = a(ba)* → True: sliding rule (rs)*r = r(sr)*. Both = {a, aba, ababa, …}.
    (a|b)* = (a*b*)* → True: every word is a sequence of a's and b's, each letter is one a*b* block.
    (ab)* = a*b* → False: a ∈ a*b* but a ∉ (ab)* (also aab).
  2. R = ends with bb, S = starts with b.
    In R not S: abb · in S not R: b · in both: bb · in neither: a

E3

1. At least one a: b*a(a|b)*
2. At most one a: b* | b*ab* = b*(a|ε)b*

q2 = dead state (a second a).

3. Even number of a: b*(ab*ab*)* = (b|ab*a)*

q0 = even, q1 = odd. ε is accepted (0 a's).

E4

1. L = {aba, bab}: exactly two words. Glushkov: a1 b2 a3 | b4 a5 b6; First = {a1, b4}, Last = {a3, b6} ⇒ F = {3, 6}; successors a1→b2, b2→a3, b4→a5, a5→b6.

2. L = repetitions of aba only, or repetitions of bab only: {ε, aba, abaaba, …, bab, babbab, …}. No mixing: ababab (= aba·bab) ✘ — same idea as a*|b*.
Glushkov: (a1 b2 a3)* | (b4 a5 b6)*. Nullable ⇒ 0 ∈ F. F = {0, 3, 6}. Successors: a1→b2, b2→a3, a3→a1 (star), b4→a5, a5→b6, b6→b4 (star).

3. Contains bbb: (a|b)*bbb(a|b)*. State = number of b's read in a row (A: 0, B: 1, C: 2, D: bbb found). An a sends back to A.

4. Complement of 3: the DFA is complete ⇒ flip the states (A, B, C final, D non-final = dead).

RegEx: (a|ba|bba)*(ε|b|bb) — exactly the class exercise of slide 61! Blocks a, ba, bba never make 3 b's; the end adds at most bb.

2. Not deterministic: from 0 (and 1, 2), reading a goes to 1 and 3 ⇒ ambiguity ⇒ NFA. Also 3, 4 have no a-transition.

3. Rows 0, 1, 2 are identical ⇒ call them S. Subset construction:

δ'([S],a) = [S,3] ← new δ'([S],b) = [S] δ'([S,3],a) = [S,3] δ'([S,3],b) = [S,4] ← new δ'([S,4],a) = [S,3] δ'([S,4],b) = [S,5] ← new δ'([S,5],a) = [S,3] δ'([S,5],b) = [S] A = [S] B = [S,3] C = [S,4] *D = [S,5] (contains 5)

4. Step0: (D) (A,B,C) · Step1: C –b→ D final, A and B –b→ non-final ⇒ (D) (C) (A,B) · Step2: B –b→ C, A –b→ A ⇒ (D) (C) (B) (A). All separated ⇒ minimal (4 states).

5. aabb: A –a→ B –a→ B –b→ C –b→ D ✔ accepted · abab: A –a→ B –b→ C –a→ B –b→ C ✘ (C not final).

E6

  1. See drawing (0 loops on b).
  2. Every state has exactly one a and one b ⇒ complete and unambiguous ⇒ deterministic.
  3. ab: 0→1→2 ✔ · aab: 0→1→0→0 ✘ · abab: 0→1→2→3→2 ✔ · abb: 0→1→2→0 ✘
  4. Step0: (2) (0,1,3) · Step1: 1 –b→ 2 and 3 –b→ 2 (final), 0 –b→ 0 ⇒ (2) (0) (1,3) · Step2: 1 –a→ 0, 3 –a→ 1: different groups ⇒ (2) (0) (1) (3) ⇒ already minimal.

E7

a) Words over {a,b} that contain ba: (a|b)*ba(a|b)* = a*bb*a(a|b)*. Deterministic and complete.

b) Words over {a,b,c} that start with a and end with bc: a(a|b|c)*bc. State 3 = last letter b, 4 = ends with bc. Deterministic, not complete (state 1 has no b, c ⇒ add a dead state).

c) Number of b different from 2 (0, 1, or at least 3): a* | a*ba* | a*ba*ba*b(a|b)*. Deterministic and complete.

d) Exactly two b: a*ba*ba*. State 4 is a dead state. Deterministic and complete.

e) Same automaton, final and non-final states flipped ⇒ d) is the complement of c).

Method for any automaton: find what each state "remembers" (number of b's, last letter…), then follow start → final paths: loop = *, choice = |.

E8

1. Nothing goes to 4 ⇒ 4 is unreachable ⇒ delete it.

Step0: (3,7) (1,2,5,6) Step1: 2 –b→ 3 and 6 –b→ 7 (final); 1 –b→ 5, 5 –b→ 1 (non-final) ⇒ (3,7) (2,6) (1,5) Step2: 1: a→2, b→5 5: a→6, b→1 ⇒ same groups 2: a→6, b→3 6: a→2, b→7 ⇒ same groups 3: a→6, b→5 7: a→2, b→1 ⇒ same groups stable ⇒ fusion: {1,5} {2,6} {3,7}

4. "1,5" = nothing useful, "2,6" = last letter a, "3,7" = ends with ab. Language: words ending with ab: (a|b)*ab.
