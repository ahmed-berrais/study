✍️ How she writes things in class — copy this format on the exam

  • Automaton = 5-tuple A = (Q, VT, δ, q0, F) — always write all 5 parts.
  • States: q0, q1… or plain numbers 0,1,2… (Glushkov). Initial = incoming arrow (in tables →q0). Final = double circle (in tables *q2 or a box around it).
  • Transition table: rows = states, columns = symbols, δ in the corner. Empty cell = - or ϕ. Several targets = a set {q1, q2}.
  • NFA→DFA: one line per computation: δ'([q1], 0) = [q1, q2] → new state, then rename the new set ({q1,q2} = q3) and redraw.
  • Glushkov: number every letter with an index: a1* b2 (a3|c4)* b5. Then a "successors" table whose first row is ɸ (= start letters). Final letters are boxed.
  • Minimisation: one line per step, groups in brackets:
    Step0: (6,7,8) (1,2,3,4,5)
    Step1: (6) (7,8) (1,2,3,4,5) … then "fusion (same behaviour)".
  • Identical rows in a table → she boxes them → they are merged into one state.
  • Merged state is named with all its members: "1,2", "7,8", "0,1,3,6".

Chapter 1 — Language theory & Regular Expressions

1. Vocabulary

  • Symbol: a · Alphabet Σ: finite set of symbols {a, b}
  • String / word: finite sequence of symbols aabb
  • Language L ⊆ Σ*: a set of strings {ε, ab, aabb, aaabbb, …} (finite or infinite)
  • ε = empty string, |ε| = 0; |01101| = 5
  • Σk = strings of length k. Σ0 = {ε}; Σ={0,1} ⇒ Σ2 = {00,01,10,11}
  • Σ* = Σ0 ∪ Σ1 ∪ Σ2 ∪ … (Kleene star, all strings)
  • Σ+ = Σ1 ∪ Σ2 ∪ … ⇒ Σ* = Σ+ ∪ {ε}
  • Concatenation: x=01101, y=110 → xy = 01101110, yx = 11001101. εw = wε = w

⚠ Classic traps

  • ∅ ≠ {ε}: ∅ has no string, {ε} has one (the empty one).
  • Σ ≠ Σ1: Σ contains symbols, Σ1 contains strings of length 1.
  • xy ≠ yx in general (concatenation is not commutative).
  • L* always contains ε; L+ contains ε only if ε ∈ L.
  • {0,11}* = 0s and 1s where the 1s come in pairs: 011, 11110, ε ✔ — 01011, 101 ✘

Exercise (slide 14) — A = {a,b}, u = aa, v = bab

  • uv = aabab · (uv)² = aababaabab · u³v = aaaaaabab
  • Words of length 2: {aa, ab, ba, bb}
  • E1 = {u.v / u,v ∈ A+} = words with |w| ≥ 2; E2 = A+; E3 = A*

5. Solved exercises (slides 27–36)

R = a(a|b)ba = {aaba, abba}, S = (ab)*|(ba)*

  1. In R not S: aaba
  2. In S not R: ab (or ε, abab)
  3. In both: none! R's words (length 4) are aaba, abba; S's words of length 4 are abab, baba ⇒ L(R)∩L(S) = ∅
  4. In neither: b, aa, bbb…

Give the elements:

  • ab*|c = {c, a, ab, abb, abbb, …}
  • (a+ b) = {ab, aab, aaab, …} (+ = one or more)
  • b*ab*ab* = words of {a,b} with exactly two a: aa, aba, baab…
  • (a|b*)*(c|d)* = any word of a,b followed by any word of c,d: ε, ab, ba, cd, abdc…

6. True or false? (slide 29)

  • (a*|b*) = (a|b)* → False: ab ∈ (a|b)* but not in a*|b*
  • (a|b)*b = (a|b)* → False: ε and a are not in (a|b)*b
  • (a*b)* = (a|b)*b → False: ε ∈ (a*b)* but ε ∉ (a|b)*b. (True only if we add ε: (a*b)* = ε | (a|b)*b)

To prove "False" → give ONE word that is in one side and not the other (counter-example).

Chapter 2 — Finite Automata principles · Glushkov · minimisation

1. Definition

A finite automaton (finite state machine) reads a string and answers yes if S ∈ L(G), no otherwise.

A = (Q, VT, δ, q0, F)

  • VT: finite alphabet · Q: finite set of states
  • q0: initial state · F: set of final (acceptor) states
  • δ: transition function δ : Q × VT → Q

Accepted word: w = a1a2…an is accepted if there is a path that starts in the initial state, follows the labels a1, a2, …, an and ends in a final state.

Used in: hardware design, lexical analysis (compilers), text search, robots/planning, program verification, text compression.

2. Example — strings over {0,1} containing "01"

She reasons with scenarios → one state each:

  • q0: the first 0 has not appeared yet
  • q1: a 0 appeared, waiting for a 1
  • q2: "01" was met (final, stays forever)

Glushkov construction RegEx → automaton

Method — 3 steps

  1. Number every symbol of the RegEx from 1 (each symbol appears once) → RE2.
    a*b(a|c)*b → a1* b2 (a3|c4)* b5
    States: q0 = 0, Q = {0,1,…,n} (n = number of letters).
  2. Build A':
    1. Start letters (can begin a word) → arcs 0 → i labelled ai
    2. End letters (can finish a word) → F = their numbers. If ε ∈ L(RE) add 0 to F!
    3. Factors of length 2 aiaj (aj can come right after ai) → arc i → j labelled aj
  3. Erase the indices (a3 → a) and draw the automaton A.

Rule: an arc always goes INTO the state of the letter it reads: reading aj ⇒ go to state j.

After minimisation (3 ≡ 5):

Minimisation of automata same language, fewest states

Method

Why: less memory/computation, easier to read; used in compilers, pattern matching, model checking.

  1. Remove unreachable states (mark everything reachable from the start; delete the rest).
  2. Step0: split into 2 groups → (final states) (non-final states).
  3. For every state of a group, look which group each letter sends it to. States of a group that go to different groups are distinguishable → split the group.
  4. Repeat (Step1, Step2, …) until nothing splits any more.
  5. Each final group = one state ("fusion"). Initial = group containing the old initial; final = groups of old finals.

Two states are distinguishable if one word leads one of them to a final state and the other to a non-final one.

Chapter 3 — Deterministic & non-deterministic automata

1. Definitions

  • Completely defined: for each state q and each symbol s ∈ Σ there is at least one transition labelled s leaving q.
  • Unambiguous: for each state q and symbol s there is at most one transition labelled s leaving q.
  • DFA (deterministic) = completely defined AND unambiguous ⇒ exactly one arrow per (state, symbol). No ε-arrows.
  • NFA (non-deterministic) = presents ambiguity: several arrows with the same symbol from one state, or ε-arrows. "We cannot deduce the next state."

How to complete a DFA: add a dead state (trap) that receives every missing transition and loops on all symbols.

Every NFA has an equivalent DFA (same language) → subset construction below.

2. Activity (slide 66) — solved

  • q1 –1→ q0 or q2 ⇒ ambiguity ⇒ NFA; q0 and q1 have no 0-arrow ⇒ not completely defined.
  • 101: q0 –1→ q1 –0→ ? no transition ⇒ rejected (not modeled)
  • 1111: q0→q1→q2→q2→q2 ⇒ accepted
  • 1101: q0→q1→q2 –0→ q1 –1→ q2 ⇒ accepted

3. Build a DFA from a sentence — her recipe

  1. List the strings of L: L = {0, 00, 01, 000, …}
  2. Draw the shortest accepted word as a path.
  3. Add the other arrows so that every state has one arrow per symbol.
  4. Words that can never be accepted → dead state.

Starts with 0 over {0,1}:

Length exactly 2: L = {00, 01, 10, 11}

4. Contains "aabb" — and the complement trick

State = how much of "aabb" is matched (A: nothing, B: a, C: aa, D: aab, E: found). D –a→ B because "aaba" ends with "a".

Does NOT contain aabb → flip the states: 1. final → non-final, 2. non-final → final.

⚠ Flipping only works on a complete DFA (add the dead state first, never on an NFA).

NFA → DFA subset construction

Method (M = (Q,Σ,δ,q0,F) → M' with L(M) = L(M'))

  1. Q' = ϕ.
  2. Add [q0] to Q' and compute its transitions.
  3. For every state of Q' and every symbol, compute the set of reachable states: δ'([q1,q2], 0) = δ(q1,0) ∪ δ(q2,0). If the set is new → add it to Q' ("new state").
  4. Stop when no new state appears.
  5. Final states of the DFA = every set that contains a final state of the NFA.

States never reached from [q0] (e.g. [q2] below) are unreachable → drop them. ϕ = dead state.

With ε-arrows: start from ε-closure(q0) (q0 + everything reachable by ε only), and after each move take the ε-closure again.

Exam-day checklist

Which method for which question?

Question says…Do…
"Give the RegEx of…"Pattern table (Ch1 §4)
"Give the elements / words of…"List the 4–5 shortest words + "…"
"Is this equality true?"Counter-example word
"Build the automaton of this RegEx"Glushkov (number → successors → draw)
"Minimise"Remove unreachable → Step0 (F)(non-F) → split → fusion
"Is it deterministic?"Check complete + unambiguous (+ no ε)

⚠ Mistakes that cost points

  • Forgetting to mark the initial arrow and the double circles.
  • Glushkov: forgetting to add 0 to F when ε ∈ L; forgetting that x* makes the next letter a possible start/end letter.
  • Minimisation: starting with anything else than (finals)(non-finals); not deleting unreachable states first.
  • NFA→DFA: forgetting a "new state" in the list, or forgetting that a set is final if it contains at least one NFA final state.
  • A DFA must have exactly one arrow per symbol in every state → add the dead state.
  • Complementing an NFA by flipping states — wrong, determinise first.
