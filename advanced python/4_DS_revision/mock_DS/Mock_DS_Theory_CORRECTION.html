Part III — Short questions (4 pts · 1 per question)

S1. The column quantity of a CSV contains whole numbers, but pandas loaded it as float64 (1.0, 2.0…). Why? What must you do before astype("int64")?
The column contains missing values: NaN is a float, so the whole column becomes float64. Before converting, handle the NaN (dropna(subset=["quantity"]) or fillna(...)), otherwise astype("int64") raises an error.
S2. Give two different treatments for missing values with an example of when each is appropriate. Why must we not replace all missing values by 0?
• Fill: a category → a label (payment_method → "Unknown") or the mode; a number with a business rule → median of the group (missing price → median price of the same product). • Drop the rows: when a key field is missing (order_date), with dropna(subset=[...]). (Also: drop the column if most values are missing, after asking the business.) Not 0: it creates fake values (price 0, age 0) and biases the averages. Every choice must be documented.
S3. Explain the difference between df.loc and df.iloc. Give an example where they return different rows.
loc selects by labels (index labels, column names, masks) and its slices include the end; iloc selects by integer positions and excludes the end. After a filter the index has gaps: if the labels are 0, 2, 5, 7, then df.loc[2:5] returns labels 2 and 5, while df.iloc[2:5] returns positions 2–3 → labels 5 and 7. Even with 0…n: loc[0:3] = 4 rows, iloc[0:3] = 3 rows.
S4. What does orders.groupby("product_id")["unit_price"].transform("median") return, compared with .median()? Why is it useful for cleaning?
.median() returns one value per product (a short Series indexed by product_id). .transform("median") returns a Series of the same length as orders, aligned with its rows: each row gets the median of its own product. It can be passed directly to fillna: orders["unit_price"].fillna(orders.groupby("product_id")["unit_price"].transform("median")).

Part IV — Write the code by hand (4 pts)

2 ptsC1. Write a function grade(score) that returns "Excellent" if score ≥ 16, "Good" if ≥ 12, "Pass" if ≥ 10 and "Fail" otherwise. Then, for scores = [8.5, 12, 17.25, 10, 9.75, 14], print each score with its grade and print how many students passed (score ≥ 10) and the class average.
def grade(score):
    if score >= 16:
        return "Excellent"
    elif score >= 12:
        return "Good"
    elif score >= 10:
        return "Pass"
    else:
        return "Fail"

scores = [8.5, 12, 17.25, 10, 9.75, 14]
passed = 0
for s in scores:
    print(s, "->", grade(s))
    if s >= 10:
        passed += 1
print("Passed:", passed)                         # 4
print("Average:", sum(scores) / len(scores))     # 11.916666...
2 ptsC2. A DataFrame orders has the columns order_id, product_id, city, quantity, unit_price. Write the code to: (a) remove the duplicated rows; (b) clean city (spaces and upper/lower case); (c) keep only the lines with at most 10 units; (d) fill the missing unit_price with the median price of the same product; (e) create revenue = quantity × unit_price; (f) display the total revenue per city, from highest to lowest; (g) export the result to orders_clean.csv without the index.
orders = orders.drop_duplicates()                                    # (a)
orders["city"] = orders["city"].str.strip().str.title()              # (b)
orders = orders[orders["quantity"] <= 10].copy()                     # (c)
med = orders.groupby("product_id")["unit_price"].transform("median")
orders["unit_price"] = orders["unit_price"].fillna(med)              # (d)
orders["revenue"] = orders["quantity"] * orders["unit_price"]        # (e)
print(orders.groupby("city")["revenue"].sum().sort_values(ascending=False))   # (f)
orders.to_csv("orders_clean.csv", index=False)                       # (g)
